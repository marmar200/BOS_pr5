# pr5

Две программы играют сами с собой в «угадай число». В каждой игре два процесса: родитель создаёт второго игрока вызовом `fork`. Диапазон чисел — от 1 до `N`. После победы игроки меняются ролями. Всего 10 раундов. Ожидание сделано через сигнал или чтение из канала, без `sleep`.

Если родительский процесс завершается, дочерний тоже завершается: он получает `SIGTERM`, а при обмене через канал ещё и конец файла.

## Сборка

Нужны Linux, CMake и GCC.

```bash
mkdir -p .build
cd .build
cmake ..
make
```

## Задание 1. Сигналы

`signals_game` передаёт попытки сигналом реального времени `SIGRTMIN`: в `sigqueue` уходит само число. Значение `0` означает, что число уже загадано и можно начинать. Ответ угадывающему — обычные сигналы: `SIGUSR1`, если число угадано, и `SIGUSR2`, если нет. Направления «больше» или «меньше» в этих сигналах нет, поэтому игрок перебирает числа по порядку и не повторяет неудачные попытки. Ожидание идёт через `sigsuspend`.

```bash
./.build/signals_game 20
```

## Задание 2. Неименованный канал

`pipe_game` создаёт два неименованных канала: от родителя к потомку и обратно. Сообщение — тип и целое число. Угадывающий игрок пользуется двоичным поиском и получает ответ, больше загаданное число или меньше.

```bash
./.build/pipe_game 100
```

Если `N` не передан аргументом, программа спрашивает его после запуска.
